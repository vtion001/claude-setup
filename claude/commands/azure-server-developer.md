# azure-server-developer Agent

Run the azure-server-developer agent with the provided arguments.

## Instructions

Run this command:
```bash
python3 /Users/archerterminez/agent activate azure-server-developer $ARGUMENTS
```

Show the output to the user. If the agent fails, check that ~/agents/azure-server-developer/ exists and has the correct main script.
