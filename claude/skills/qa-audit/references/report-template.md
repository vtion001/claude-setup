## Linear Issue Template

When auto-filing to Linear, use this structure for each finding:

**Title:** `{Page name} — {concise problem description}`

**Description:**
```markdown
## Problem

{Clear description with context}

## Screenshot

![{alt}]({url or path})

## Root Cause

{Technical explanation}

## Files Affected

* `{file_path}:{line}` — {description}

## Fix

{Specific code changes or approach}

## Verification

{Steps to confirm the fix}
```

**Field Mapping:**

| Finding Severity | Linear Priority | Linear Value |
|-----------------|----------------|--------------|
| Critical | Urgent | 1 |
| High | High | 2 |
| Medium | Medium | 3 |
| Low | Low | 4 |

**Labels:** `["Bug"]` for all findings
**Project:** Auto-detect from context or user input
**Assignee:** Current user (use `"me"`)

---

## Screenshot Naming Convention

```
{page-slug}_{finding-or-baseline}_{timestamp}.png
```

Examples:
- `dashboard_baseline_20260519.png`
- `calls_broken-filter_20260519.png`
- `qa-logs_counter-mismatch_20260519.png`
- `agent-profiles_no-pagination_20260519.png`
- `sidebar_broken-logo_20260519.png`

Save all screenshots to the configured `SCREENSHOT_DIR` (default: `./qa-audit-screenshots/`).
